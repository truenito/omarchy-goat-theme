# Goat

*A quiet mountain theme for [Omarchy](https://omarchy.org/), by gvbrl.*

Above the tree line the fog rolls in slowly. The pines go soft and grey, and
somewhere on the ridge a goat stands perfectly still, sure-footed and in no
hurry at all. Goat is that moment kept on your desktop: calm, unhurried, a
little old-fashioned in the best way.

- **Misty slate** backgrounds, like wet stone under low cloud
- **Fog parchment** text, warm and easy on the eyes
- **Moss, lichen and larch gold** for the details
- **Deep jade** window borders, the colour of polished stone against dark walnut
- **A grainy, retro fog** in the wallpapers: soft daylight mist, silver dusk haze

## Install

```bash
omarchy theme install https://github.com/truenito/omarchy-goat-theme
```

This repo is the theme alone. The full goat look and feel (wallpapers that
follow the sun, cream folder icons, Zen and GTK styling, bar layout, hotkeys)
lives in [truenito/goat](https://github.com/truenito/goat).
